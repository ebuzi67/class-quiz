줄넘기 챌린지

화면 속 내 몸에 줄이 돌아가요!
줄이 발밑을 지나갈 때 콩! 점프하면 성공. 하트 3개가 다 없어지면 끝!

놀이

몇 명?

둘이서 할 때는 화면 왼쪽이 1P(🐰), 오른쪽이 2P(🐻)예요. 서로 부딪히지 않게 떨어져 서요.

줄 빠르기

"휙~" 소리에 줄이 머리 위로, "탁!" 소리에 발밑으로 지나가요. 소리에 맞춰 뛰면 쉬워요.

카메라

놀이 방법

  1. 노트북·태블릿을 세워 두고 2~3걸음 뒤로 물러나요. 머리부터 발끝까지 보여야 해요.
  2. 가상 줄넘기: 손을 옆으로 내리고 줄을 돌리는 흉내를 내요. 줄이 발밑에 올 때 두 발로 콩! 뛰어요.
  3. 진짜 줄 30초: 진짜 줄넘기를 들고 30초 동안 몇 번 넘는지 세어 줘요.
