# 픽셀 마법사 연구소

> 작은 픽셀에 마법을 걸어봐!

코딩 블록으로 픽셀 그림을 그리고, 저장하고, 움직이는 애니메이션까지 만드는 초등 코딩 수업용 웹앱이에요.
회원가입도 서버도 필요 없어요. 브라우저만 있으면 바로 쓸 수 있어요.

- 수업 주소: `https://ebuzi67.github.io/class-quiz/pixel-lab/`
- 대상: 초등 1~6학년 (주 대상 2~4학년)
- 화면: PC 1366×768(100%)에서 스크롤 없이 한 화면, 1280×720도 지원, 태블릿은 화면에 맞게 바뀌어요.

## 세 가지 모드

| 모드 | 하는 일 |
|---|---|
| 마법 따라 그리기 | 목표 그림을 블록으로 똑같이 그리는 미션 12개. 힌트 3단계, 틀린 칸 표시, 완성 별·효율 별 |
| 자유 픽셀 공방 | 8×8 / 10×10 / 16×16 도화지에 블록으로 작품 만들기. 되돌리기, 저장·불러오기, PNG 내려받기 |
| 움직이는 픽셀 극장 | 프레임을 추가·복사·삭제·순서 바꾸기, 앞 프레임 비추기, 재생, 저장, GIF·프레임 PNG 내려받기. 예시 5개 |

### 미션 차례 (새 개념을 하나씩)

| 번호 | 미션 | 수준 | 핵심 학습 |
|---|---|---|---|
| 1 | 첫 번째 마법 점 | 쉬움 | 색칠 명령 |
| 2 | 반짝이는 가로줄 | 쉬움 | 이동과 순서 |
| 3 | 차곡차곡 마법 계단 | 쉬움 | 방향 명령 |
| 4 | 네모난 마법 창문 | 쉬움 | 네 방향과 패턴 |
| 5 | 하트 만들기 | 보통 | 좌표와 색 고르기 |
| 6 | 반복되는 무지개 | 보통 | 반복문 |
| 7 | 마법사의 꽃밭 | 보통 | 반복과 패턴 |
| 8 | 별빛 장식 | 보통 | 효율적인 명령 |
| 9 | 귀여운 버섯 | 보통 | 색 변경과 반복 |
| 10 | 마법사의 시험 | 도전 | 종합 |
| 11 | 줄무늬 마법 양탄자 | 도전 | 중첩 반복 |
| 12 | 별빛 바둑판 | 도전 | 효율적인 알고리즘과 디버깅 |

## 수업에서 쓰는 방법

- **블록 넣기**: 왼쪽 「블록 서랍」의 블록을 누르면 「마법 주문서」에 들어가요. 끌어다 놓아도 돼요.
- **블록 고치기**: 주문서의 블록을 누르면 `위로 / 아래로 / 복사 / 삭제` 버튼이 나와요. 끌어서 옮길 수도 있어요.
- **반복 블록**: 반복 블록 안의 「여기에 넣기」를 누른 다음 블록을 넣으면 안으로 들어가요. 반복 안에 반복도 넣을 수 있어요.
- **실행 도구**: 실행 / 일시정지 / 한 단계 / 처음부터 / 지우기 / 속도 4단계.
- **디버깅**: 실행 중인 블록이 강조되고, 도화지에 마법 펜 위치가 점선 테두리와 지팡이로 보여요.
  펜이 도화지 밖으로 나가려 하면 그 블록에 느낌표(!)가 붙고 이유를 알려 줘요. 목표와 다른 칸은 빗금으로 표시돼요.
- **선생님 메뉴** (오른쪽 위 모자 버튼): 「선생님 모드」를 켜면 모든 미션이 열리고 미션 화면에 「정답 코드」 버튼이 생겨요.
  그 컴퓨터의 미션 결과(별, 사용한 블록 수)도 여기서 볼 수 있어요.
- **전체 화면 / 소리 끄기 / 사용 방법**: 오른쪽 위 버튼.
- **작품 모으기**: 공방의 「내 작품」에서 작품마다 PNG로 내려받을 수 있어요. 극장은 GIF로 내려받아요.

### 실행 규칙

- 좌표는 왼쪽 위가 (0, 0)이고, 마법 펜은 항상 (0, 0)에서 출발해요. 처음 색은 보라예요.
- 「색칠하기」 블록을 실행할 때만 칸이 칠해져요. 이동 블록은 펜만 옮겨요.
- 실행할 때마다 도화지를 비우고 처음부터 다시 그려요.
- 도화지 밖으로 나가는 이동, 99번을 넘는 반복, 1500걸음을 넘는 실행은 안전하게 멈추고 이유를 알려 줘요.
- 미션은 **그림만 같으면 성공**이에요. 블록 순서가 정답 예시와 달라도 돼요.

### 저장되는 곳

모든 자료는 **그 컴퓨터, 그 브라우저**의 저장소(localStorage)에 남아요. 새로고침하거나 껐다 켜도 그대로 있어요.
다른 컴퓨터로는 옮겨지지 않으니, 작품을 모을 때는 PNG·GIF로 내려받아 주세요.
(브라우저의 "인터넷 사용 기록 지우기"로 사이트 데이터를 지우면 작품도 지워져요.)

## 설치하고 실행하기

Node.js 18 이상이 필요해요.

```bash
npm install        # 처음 한 번
npm run dev        # 개발용으로 열기 (주소가 화면에 나와요)
npm test           # 자동 테스트 (실행 엔진, 미션 12개 정답 확인, GIF, 예시 작품)
npm run build      # 배포용 파일을 dist/에 만들기
npm run preview    # 만든 dist/를 미리 보기
```

### 배포

`dist/` 폴더 안의 파일을 그대로 정적 웹 호스팅(GitHub Pages, Netlify, 학교 서버 등)에 올리면 돼요.
주소가 어느 폴더든 열리도록 상대 경로로 빌드해요.

- **class-quiz 저장소 안에서는** `npm run publish-site`를 실행하면 빌드한 뒤 저장소의 `pixel-lab/` 폴더로 복사해요. 그다음 커밋해서 올리면 돼요.
- 다른 곳에 올릴 때는 `public/manifest.json`의 `"id"`를 그 주소에 맞게 바꿔 주세요. (앱으로 설치할 때 쓰는 이름표예요.)
- 아이콘을 바꾸려면 `make_icons.py`를 고친 뒤 `python3 make_icons.py`를 실행해요.

### 브라우저 자동 점검 (선택)

Playwright와 Chromium이 있으면 앱을 실제로 눌러 보는 점검을 돌릴 수 있어요.

```bash
npm run build && npm run preview &
node e2e/check.cjs http://localhost:4173/
```

모든 미션을 정답 코드로 실행해 성공 판정을 확인하고, 일시정지·한 단계·도화지 밖 오류, 저장·불러오기·새로고침 유지,
PNG·GIF 내려받기, 애니메이션 재생, 화면 크기(1366×768, 1280×720 등), 오프라인 열기까지 110가지를 확인해요.

## 폴더 구조

```
src/
├─ engine/            화면과 떨어진 순수 로직 (테스트하기 쉬워요)
│  ├─ types.ts        블록 데이터 모델, 색 팔레트
│  ├─ engine.ts       실행 엔진: 한 걸음씩 실행하고 블록·좌표·색·바뀐 칸·오류를 알려 줘요
│  ├─ tree.ts         블록 넣기·빼기·옮기기
│  ├─ missions.ts     미션 12개 (목표 그림, 힌트, 정답 예시)
│  └─ generate.ts     그림 → 블록 프로그램 (극장 예시에 써요)
├─ lib/               저장소, 효과음, GIF 인코더, 내보내기, 실행 훅(useRunner)
├─ components/        도화지, 블록 편집기, 실행 도구, 팝업, 아이콘
├─ modes/             세 가지 모드 화면
├─ App.tsx  main.tsx  styles.css
public/               manifest.json, 아이콘
scripts/              publish.mjs (저장소로 복사), zip.mjs (압축파일 만들기)
e2e/check.cjs         브라우저 자동 점검
```

- 미션을 고치거나 더하려면 `src/engine/missions.ts`만 고치면 돼요. `npm test`가 정답 예시로 풀리는지 확인해 줘요.
- 블록 데이터(`types.ts`)와 실행 엔진(`engine.ts`)은 화면 코드와 떨어져 있어요. 화면은 엔진이 알려 주는 걸음별 결과만 받아서 보여 줘요.

## 기능 상태

모두 실제로 작동하는 기능이에요.

- 블록: 위·아래·왼쪽·오른쪽 이동, 색칠하기, 색 고르기(12색), 지우기, 반복하기(중첩 가능)
- 실행: 실행, 일시정지, 이어서 실행, 한 단계, 처음부터, 지우기, 속도 4단계
- 미션 12개, 힌트 3단계, 틀린 칸 표시, 목표 비춰 보기, 완성 별·효율 별, 완료 도장, 잠금 해제, 칭호, 진행 저장
- 공방: 크기 3가지, 손으로 칠하기·지우개(보조), 되돌리기·다시 하기, 저장·불러오기·삭제, PNG
- 극장: 프레임 편집, 앞 프레임 비추기, 재생·속도·반복, 프레임마다 블록 유지, 저장·불러오기, GIF, 프레임 PNG, 예시 5개
- 효과음과 소리 끄기, 전체 화면, 선생님 메뉴, 앱 설치(PWA)와 오프라인 사용

아직 없는 기능 (버튼도 만들지 않았어요)

- 극장 모드의 되돌리기 (공방에만 있어요)
- 작품을 다른 컴퓨터로 옮기는 기능 (PNG·GIF로 내려받기만 돼요)
- 여러 학생의 결과를 한곳에 모아 보는 기능 (서버가 없어서 컴퓨터마다 따로 저장돼요)
