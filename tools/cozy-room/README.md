# 🏠 모모의 코딩 하루 (cozy-room)

3D 인형집 방에서 캐릭터 **모모**가 스스로 하루를 보내요. 학생은 가구를 눌러 행동을 부탁하거나, **블록 코딩**으로 모모의 하루를 직접 짜요.
방과후 코딩 수업(초등 3~6학년, 6~8차시)에 맞춰 만들었어요.

- 주소: `https://ebuzi67.github.io/class-quiz/cozy-room/`
- 휴대폰·태블릿에 앱으로 설치할 수 있고, 한 번 열면 인터넷 없이도 돌아가요.
- 로그인이나 서버를 쓰지 않아요. 학생 코드와 미션 도장은 그 기기의 브라우저에만 저장돼요.

---

## 1. 실행하기

```bash
cd tools/cozy-room
npm install        # 처음 한 번
npm run dev        # 개발용 서버 → 화면에 나오는 주소(http://localhost:5173)를 열어요
```

| 명령 | 하는 일 |
| --- | --- |
| `npm run dev` | 고치면서 바로 보기 (파일을 저장하면 화면이 저절로 바뀌어요) |
| `npm test` | 블록 실행기·공유 코드·설정 파일·길 찾기 테스트 |
| `npm run build` | `dist/`에 올릴 파일 만들기 |
| `npm run publish-site` | 테스트 → 빌드 → 저장소 맨 위 `cozy-room/` 폴더로 복사 (GitHub Pages용) |
| `npm run e2e` | 브라우저로 실제로 눌러 보는 자동 점검 (먼저 `npm run build && npm run preview`) |
| `python3 make_icons.py` | 앱 아이콘 다시 만들기 |

> ⚠️ 저장소의 `cozy-room/` 폴더는 만들어진 결과물이에요. 직접 고치지 말고, 여기(`tools/cozy-room/`)를 고친 뒤 `npm run publish-site`를 돌려요.

## 2. 조작법

| 하고 싶은 것 | 마우스 | 터치 | 키보드 |
| --- | --- | --- | --- |
| 방 돌리기 | 끌기 | 한 손가락으로 끌기 | 화살표 키 (방 화면을 누른 뒤) |
| 확대·축소 | 휠 | 두 손가락 벌리기·오므리기 | `+` / `-` |
| 행동 부탁하기 | 가구·화장품·모모 누르기 → 메뉴 | 누르기 → 메뉴 | `Enter`나 📋 물건 목록 → 메뉴 |
| 메뉴 닫기 | ✕ 또는 빈 곳 누르기 | 같아요 | `Esc` |

오른쪽(휴대폰은 아래) 도구 버튼:

- **⏸️ 자동 멈춤**: 모모가 스스로 하는 행동을 멈춰요. 지금 하는 행동은 끝까지 해요. 부탁한 행동은 계속 들어줘요.
- **📋 물건 목록**: 3D 화면을 누르기 어려울 때 목록에서 골라요. 키보드와 화면 읽기 프로그램으로도 쓸 수 있어요.
- **🎥 카메라**: 처음 보던 자리로 돌아가요.
- **🔇 소리**: 처음에는 꺼져 있어요 (교실용).
- **🐢/🐇 빠르기**: 2배 빠르게. 수업 시간을 아낄 때 좋아요.
- **🔍 큰 화면**: 전자칠판·TV용으로 버튼과 글자를 크게 해요.
- **❓ 도움말**: 첫 화면 조작 안내를 다시 봐요.
- **🧩 코딩 모드**: 블록 코딩 패널을 열어요.

### 행동을 부탁하면 이렇게 돼요

1. 모모가 **지금 하는 행동을 마쳐요.** 단, 자동으로 고른 행동을 하러 아직 걸어가는 중이었다면 그 걸음은 멈추고 바로 부탁을 들어줘요.
2. 가구까지 **길을 찾아 걸어가요** (가구를 피해서 돌아가요).
3. 가구 쪽(또는 정해진 방향)을 보고 서거나, 의자·방석·침대에 **앉거나 누워요**.
4. 물건을 **손에 들고** 행동해요. 표정이 바뀌고, 끝나면 하트·별·왕관 효과가 나와요.
5. 같은 부탁을 두 번 하면 한 번만 들어가요. 부탁은 4개까지 줄을 서요.

## 🐾 나의 반려동물 & 📖 동물 도감 (`pet.html`)

오른쪽 도구 버튼의 **🐾 반려동물**, **📖 도감**에서 들어가요. 화면 위 **🏠 모모의 방**을 누르면 돌아와요.
처음에 "저요! 저요! 도와주세요"(`help/`)에서 만든 반려동물 기능을 이 앱으로 옮겨 왔어요 (지금은 `help/`에는 없어요).

| 기능 | 내용 |
|---|---|
| 반려동물 고르기 | 강아지 6, 고양이 6, 곤충 6 중 하나를 골라 이름을 지어요. 모두 같은 그림체의 3D 캐릭터예요 |
| 돌보기 | 강아지: 사료·물·산책·공놀이·쓰다듬기·관찰 / 고양이: 간식·물·장난감·낚싯대·쓰다듬기·관찰 / 곤충: 먹이(곤충 젤리)·물 뿌리기·관찰·놀이터 산책·성장 과정 보기 |
| 성장 | 경험치로 아기 → 어린이 → 성장 → 성숙. 단계가 오르면 몸이 커져요. 친밀도는 0~100 |
| 꾸미기 | 강아지·고양이는 실내 방, 곤충은 사육장. 배경·방석·장난감·그릇·작은 집·나무와 풀·곤충 사육장·곤충 놀이터·장식. 물건은 끌어서 옮겨요 |
| 보상 | 아이템과 배지 10가지. 성장 단계·경험치·도감 발견 수·해 본 놀이 종류로 열려요 |
| 동물 도감 | 18종. 3D 모델을 돌려 보며 생김새·생태·재미있는 사실을 봐요. 곤충은 분류·서식지·먹이·한살이(알 → 애벌레 → 번데기 → 어른벌레)까지 |
| 수집 | 카드를 열면 "발견". 전체 완성률과 강아지·고양이·곤충별 현황. 반려동물이 없어도 누구나 모든 도감을 볼 수 있어요 |
| 다른 기기로 옮기기 | 📲 이어하기 → `PET1-`로 시작하는 **백업 코드**를 복사해 다른 기기에 붙여 넣어요 (서버를 쓰지 않아요) |

**모모의 방에 놀러 와요**

- 반려동물을 고르면 모모의 방에도 나타나서 돌아다니고, 가끔 모모 곁으로 와요.
- 방 안의 반려동물을 누르면 메뉴가 나와요: **🐾 반려동물 쓰다듬기, 🎾 반려동물과 놀기, 🥣 반려동물 밥 주기**. 모모가 걸어가서 하고, 반려동물도 같이 움직여요.
- 이 세 행동은 **코딩 블록**(🎬 행동하기)에도 있고, 모자 블록에서 **"물건을 누르면 → 🐾 내 반려동물"** 이벤트도 쓸 수 있어요.
- 모모가 돌봐 주면 반려동물 화면의 친밀도 +1, 경험치 +3을 받아요 (하루 5번까지, 그 뒤에도 계속 놀 수 있어요).
- 반려동물이 없을 때 코드가 이 행동을 시키면, 모모가 "아직 반려동물이 없어요!"라고 말하고 다음 블록으로 넘어가요.

**지킨 약속**: 돌보지 않아도 아프거나 사라지거나 줄어드는 것은 없어요. 게임 속 성장 단계는 실제 동물의 성장과 다르다고 따로 알려 줘요. 저장 데이터에 학생 이름 같은 개인 정보는 없어요.

**파일**: `pet.html`, `src/pet/` (`data.js` 동물·도감 정보와 아이템·배지, `models.js` 3D 모델, `scene.js` 3D 무대, `app.js` 화면, `save.js` 저장·백업 코드, `png.js` PNG로 바꾸기, `base.css`·`pet.css` 디자인, `theme.css` 모모의 방 색), `src/engine/petBuddy.js` (모모의 방에 놀러 오는 반려동물).
**동물 그림**: 고르기·도감 카드와 큰 그림은 사진 `art/pets-sheet.webp`(6칸 × 3줄)을 잘라 만든 그림이에요. `python3 make_pet_art.py`가 한 마리씩 잘라 배경을 지우고 `public/pet/img/`에 `<동물>.webp`(그림)와 `<동물>-sil.png`(아직 발견하지 않은 동물의 그림자)를 만들어요. 경로는 `src/pet/png.js`에 적혀 있어요. 같은 배치로 그린 새 사진으로 바꾸고 다시 돌리면 그림이 바뀌어요. 돌보기 방과 모모의 방에서는 움직여야 해서 3D 모델이 나와요.

**3D 모델**: `src/pet/models.js`의 `DOGS`·`CATS`·`BUGS` 설정표(색, 귀·꼬리 모양, 무늬)와 만드는 함수로 그려요. 참고 그림 `art/ref-dogs.png`, `art/ref-cats.png`, `art/ref-bugs.png`(앞·옆·뒤·비스듬히)에 맞춰 다듬었어요. `npm run dev`를 켜고 `http://localhost:5173/dev/turnaround.html?cat=dog`(또는 `cat`, `bug`)를 열면 3D 모델을 참고 그림과 같은 배치로 찍어서 비교할 수 있어요 (이 페이지는 사이트에 올라가지 않아요).

**나중에 붙일 수 있는 학급 공동 공간**: `src/pet/save.js`의 `publicCard()`가 반려동물 모습(종류·이름·성장 단계·장식·배경)만 담은 공개 카드를 만들어요. 학생 이름과 개인 정보는 넣지 않아요. 친구들 반려동물 구경하기, 작은 마을, 학급 정원은 이 카드만 모아서 보여 주면 돼요.

## 3. 코딩 모드 (블록)

| 블록 | 뜻 | 배우는 개념 |
| --- | --- | --- |
| 🎬 행동하기 [행동] | 고른 행동을 해요 | 순서 |
| 🔁 [3]번 반복 | 안에 든 블록을 여러 번 | 반복 |
| 🔀 만약 [상태] [>] [70] 이면 / 아니면 | 상태 값에 따라 다르게 | 조건, 변수 |
| ⏱️ [1]초 기다리기 | 잠깐 멈춰요 | 순서 |
| 💬 [글자] 말하기 | 말풍선 | 출력 |
| 😊 표정 [활짝] | 표정을 바꿔요 | |

- 맨 위 초록 칸(**모자 블록**)이 "언제 시작할지"예요: **▶ 실행 버튼을 누르면 / 모모를 누르면 / 물건을 누르면** (이벤트).
- **블록 넣기**: 꾸러미의 블록을 누르면 테두리가 진한 칸(선택한 칸)의 끝에 들어가요. 끌어다 원하는 자리에 놓을 수도 있어요.
- **지우기**: 블록의 ✕, 또는 블록을 꾸러미나 🗑️로 끌어다 놓기. 키보드는 블록에서 `Delete`.
- **순서 바꾸기**: 끌어다 놓기, 또는 키보드 `Alt + ↑/↓`.
- **▶ 실행 / ■ 멈춤 / 한 단계씩**: 실행 중인 블록이 반짝여요. "한 단계씩"을 켜면 `다음 ⏭`을 누를 때마다 블록이 하나씩 실행돼요 (디버깅 연습).
- **📜 코드 보기**: 블록을 `for`, `if`가 들어간 글자 코드로 보여 줘요.
- **🔗 공유 탭**: `MOMO1-`로 시작하는 공유 코드나 링크로 친구와 코드를 주고받아요.
- 안전장치: 블록 60개, 4겹, 반복 10번, 한 번 실행에 블록 300번까지만 실행해요. 무한 반복으로 멈추는 일이 없어요.

## 4. 차시별 수업 가이드

미션은 앱의 **🏅 미션 탭**에 있고, 통과하면 도장이 찍혀요 (`src/config/missions.js`).

| 차시 | 목표 | 개념 | 미션 | 학생이 고칠 파일 | 자주 막히는 곳과 도움말 |
| --- | --- | --- | --- | --- | --- |
| 1 | 앱과 친해지기, 이벤트 맛보기 | 이벤트 | 👆 가구를 눌러 행동 2가지 부탁하기 | — | 3D 화면을 끌다가 메뉴가 안 열려요 → "살짝 톡" 누르기. 📋 물건 목록을 알려 주세요. |
| 2 | 순서대로 명령하기 | 순서 | 🔢 "시작하면" 아래 행동 3개 | — | 블록이 다른 스크립트로 들어가요 → 넣고 싶은 칸을 먼저 눌러 테두리를 진하게. |
| 3 | 같은 일을 짧게 | 반복 | 🔁 반복 블록으로 머리 3번 빗기 | — | 행동이 반복 블록 **밖**에 있어요 → 들여쓴 칸 안으로 끌어다 놓기. |
| 4 | 상황에 따라 다르게 | 조건 | 🔀 졸리면 낮잠, 아니면 책 | — | 늘 한쪽만 실행돼요 → 위쪽 💤 게이지 숫자를 보고 기준 값을 바꿔서 두 번 실행해 보기. |
| 5 | 누르면 실행되는 코드 | 이벤트 | ⚡ 화분을 누르면 물 주기 | — | 화분을 눌렀는데 메뉴만 떠요 → ▶ 실행을 먼저 눌러 "기다리는 중" 상태로 만들기. |
| 6 | 변수 관찰하기 | 변수 | 🫧 깨끗함 100 만들기 | `config/character.js` (색 바꾸기) | 어떤 행동이 깨끗함을 올리나요? → 메뉴에서 행동을 하나씩 해 보며 게이지 관찰. |
| 7 | 나만의 루틴 발표 | 모두 합치기 | 👑 블록 6개 이상 + 반복/만약 + 말하기 | `config/actions.js` (새 행동) | 발표 때는 🐇 2배속과 🔍 큰 화면을 켜면 좋아요. 공유 코드로 친구 기기에서 실행. |
| 8 (심화) | 코드로 방 꾸미기 | 데이터(객체) | 새 가구·화장품·행동 추가 | `config/furniture.js`, `products.js`, `actions.js` | 쉼표(,) 빠짐, 따옴표 짝 → 앱이 멈추지 않고 ❓ 도움말에 고칠 곳을 알려 줘요. |

**수업 팁**

- 1~5차시는 앱만 있으면 돼요 (설치, 계정 필요 없음). 6차시부터 코드 파일을 고치려면 `npm run dev`가 되는 컴퓨터가 필요해요.
- 학생 기기마다 진행이 따로 저장돼요. 새 학기에 지우려면 미션 탭 맨 아래 "도장 모두 지우기", 공유 탭 "내 코드 모두 지우기"를 눌러요.
- 학생용 인쇄 미션지는 [`docs/mission-sheet.md`](docs/mission-sheet.md)에 있어요.

## 5. 폴더 구조

```
tools/cozy-room/
├─ index.html            화면 뼈대 (버튼, 패널)
├─ src/
│  ├─ main.js            시작점: 3D·캐릭터·뇌·화면·코딩 모드를 연결
│  ├─ style.css          디자인 (큰 화면, 휴대폰, 움직임 줄이기 포함)
│  ├─ config/            ★ 학생·선생님이 고치는 파일
│  │  ├─ character.js    캐릭터 이름·색·크기·걷는 빠르기·머리 길이
│  │  ├─ furniture.js    가구 목록 (자리, 색, 서는 자리, 앉는 자리)
│  │  ├─ products.js     화장품·소품 목록 (모양, 색, 놓일 가구)
│  │  ├─ actions.js      행동 목록 (데이터 한 덩어리 = 행동 하나)
│  │  └─ missions.js     차시별 미션과 통과 조건
│  ├─ engine/            엔진 (보통은 고치지 않아요)
│  │  ├─ kit.js          도형·재질 만들기와 재사용(캐시)
│  │  ├─ character.js    캐릭터 모양, 팔 IK, 걷기, 표정, 머리카락·옷 흔들림
│  │  ├─ motions.js      몸동작 (두드리기, 세수, 양치, 빗기 …)
│  │  ├─ furnitureKit.js 가구 모양 10종
│  │  ├─ productKit.js   화장품·소품 모양 12종
│  │  ├─ world.js        방, 조명, 가구 배치, 강조 효과, 무드등·창문·화분·어지른 물건
│  │  ├─ brain.js        행동 실행기: 줄 세우기, 길 찾아 걷기, 앉기, 자동 행동 고르기
│  │  ├─ path.js         길 찾기 (A*)
│  │  ├─ particles.js    하트·별·거품·물방울·Zzz·왕관 효과
│  │  ├─ cameraRig.js    카메라 돌리기·확대·범위 제한·초기화
│  │  ├─ state.js        상태 변수 (기분·졸림·깨끗함)
│  │  ├─ validate.js     설정 파일 검사 (실수해도 멈추지 않게)
│  │  ├─ names.js        엔진이 아는 이름 목록, 가구 크기
│  │  └─ sound.js        효과음 (파일 없이 소리 만들기)
│  ├─ blocks/            블록 코딩
│  │  ├─ program.js      코드 구조, 넣기·옮기기, 공유 코드, 글자 코드 만들기
│  │  ├─ interpreter.js  블록 실행기
│  │  ├─ editor.js       블록 편집 화면 (끌어다 놓기, 키보드)
│  │  └─ runController.js 실행·멈춤·한 단계씩·이벤트 스크립트
│  └─ ui/                미션 탭, 알림·창 도우미
├─ test/                 vitest 테스트
├─ e2e/check.cjs         브라우저 자동 점검
├─ public/               manifest.json, 아이콘
├─ make_icons.py         아이콘 그리기
├─ make_pet_art.py       반려동물 사진을 잘라 그림 만들기 (art/pets-sheet.webp → public/pet/img/)
└─ scripts/publish.mjs   결과물을 저장소의 cozy-room/ 으로 복사
```

화면이 돌아가는 순서: `main.js`가 설정을 검사(`validate.js`)하고 → 방(`world.js`)과 캐릭터(`character.js`)를 만들고 → 뇌(`brain.js`)가 할 일을 골라 걷기·동작(`motions.js`)을 시켜요. 코딩 모드에서는 `runController.js`가 블록을 하나씩 읽어 뇌에게 부탁해요.

## 6. 캐릭터 고치기 — `src/config/character.js`

```js
export const character = {
  name: '모모',            // 이름 (말풍선·제목에 나와요)
  size: 1,                 // 크기 (0.8~1.2)
  walkSpeed: 1.15,         // 걷는 빠르기
  hairLength: 3,           // 뒷머리 마디 수 (1~5)
  colors: { hair: '#2b2431', pajama: '#ff8f86', ribbon: '#ff6f93', ... },
};
```

- 색은 `#` + 6글자예요. 파자마를 하늘색으로: `pajama: '#8fc9f5'`
- 모양(눈 크기, 앞머리 등)을 더 바꾸고 싶으면 `src/engine/character.js`의 `buildFace`, `buildHair`, `buildRibbon`을 고쳐요. 모두 구·캡슐·도넛 같은 기본 도형으로 만들었어요.

## 7. 새 가구 추가하기 — `src/config/furniture.js`

```js
{
  id: 'plant2', type: 'plant', name: '작은 화분', emoji: '🌱',
  pos: [-2.5, 2.2],          // 놓을 자리 [x, z]  (x: -4~4, z: -3~3)
  rot: 0,                    // 돌리기 (도)
  color: '#cbb7f5', accent: '#ffb3c4',
  spot: [0.7, 0],            // 캐릭터가 서는 자리 (가구에서 떨어진 정도)
},
```

- `target`에 `'pet'`을 적으면 내 반려동물에게 가요. 이때 `petAnim`(`'pet'` `'jump'` `'ball'` `'eat'` `'drink'`)으로 반려동물의 움직임을 정해요.
- 쓸 수 있는 `type`: `bed` `nightstand` `vanity` `sink` `shelf` `window` `plant` `teaTable` `rug` `toyBox`
- 앉는 자리가 있으면 `seat: { at: [x, z], y: 높이, face: 각도 }`를 넣어요.
- 새 **모양**을 만들려면 `src/engine/furnitureKit.js`의 `builders`에 함수를 하나 추가하고, `src/engine/names.js`의 `FURNITURE_TYPES`와 `FOOTPRINTS`(바닥 크기)에 이름을 넣어요.

## 9. 새 행동 추가하기 — `src/config/actions.js`

객체 하나만 추가하면 **클릭 메뉴, 코딩 블록, 자동 행동**에 저절로 나와요.

```js
{
  id: 'mist', name: '미스트 뿌리기', emoji: '🌫️', code: '미스트뿌리기',
  target: 'vanity',        // 가서 할 가구 (null 이면 제자리)
  seat: true,              // 의자에 앉아서
  face: 'target',          // 'target' / 'camera' / 각도
  product: 'mist',         // 손에 들 물건
  pickup: false,           // true 면 물건이 있는 곳에 먼저 들러요
  motion: 'pat',           // 몸동작 (아래 목록)
  duration: 3,             // 초
  expression: 'joy',       // 표정
  say: '촉촉!',            // 말풍선
  effects: { mood: 5, clean: 5 },   // 상태 변화
  glow: 0.2,               // 피부 반짝임 (0~1)
  finish: ['drops', 'sparkle'],     // 끝날 때 효과
  weight: 1,               // 자동 행동에서 뽑힐 확률 (0 이면 안 뽑혀요)
  wants: { clean: '<50' },          // 이럴 때 더 하고 싶어해요
  onFinish: (world) => world.growPlant(),  // (고급) 끝날 때 실행할 함수
},
```

- 몸동작(`motion`): `pat` `dropper` `washFace` `brushTeeth` `lipBalm` `blush` `comb` `sunscreen` `maskPack` `drink` `read` `nap` `water` `tidy` `press` `dance` `stretch` `wave` `jump` `petting` `playPet`
- 표정(`expression`): `happy` `joy` `closed` `sleepy` `surprised` `proud`
- 효과(`finish`): `hearts` `stars` `sparkle` `bubbles` `crown` `notes` `drops` `zzz` `steam`
- `onStart`/`onFinish`에서 쓸 수 있는 `world` 기능: `toggleLamp()` `toggleWindow()` `growPlant()` `collectMess()` `spawnMess()`
- 새 **몸동작**을 만들려면 `src/engine/motions.js`에 함수를 추가하고 `names.js`의 `MOTION_NAMES`에 이름을 넣어요. 손 위치는 `ch.reach(P, 'R', x, y, z)`로 정해요 (팔 각도는 IK가 계산해요).

**실수해도 괜찮아요.** 없는 가구·모양·몸동작을 적으면 그 행동만 빼고 실행하고, ❓ 도움말과 브라우저 콘솔에 "행동 '날기': target 'moon' 가구가 없어요." 처럼 알려 줘요.

## 10. 기술 메모

- Three.js 기본 도형만 써요 (외부 3D 모델·이미지·글꼴 없음). 무늬는 캔버스로 그려서 텍스처로 써요.
- 성능: 도형·재질을 캐시해서 다시 쓰고, 그림자 맵 하나, 픽셀 비율 1.75배 제한. 처음 몇 초 동안 프레임을 재서 느리면 픽셀 비율과 그림자 품질을 자동으로 낮춰요. 탭이 안 보이면 그리기를 멈춰요.
- 접근성: 모든 버튼에 이름, 키보드 조작, 포커스 표시, 상태 문구(`aria-live`), 게이지(`role="meter"`), 큰 화면 모드, 운영체제의 "동작 줄이기"(`prefers-reduced-motion`)를 따라 효과와 흔들림을 줄여요.
- 오류 처리: WebGL이 없으면 안내 화면, 설정 실수는 건너뛰고 알림, 그리기 중 오류는 알림만 하고 계속 돌아가요.
- PWA: `manifest.json`의 `id`는 `/class-quiz/cozy-room/`, `start_url`·`scope`는 `./`. 서비스 워커 저장소 이름은 `cozy-room-` 접두어를 쓰고 자기 옛 버전만 지워요.
